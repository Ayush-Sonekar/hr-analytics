# HR Attendance Overview (Power BI)

## Overview
Analyzes employee attendance data from April-June 2022 for AtliQ, visualizing present rates, WFH usage, and sick leave trends.

## Features
- KPI cards for overall metrics (91.83\% Present, 10.00\% WFH, 1.10\% SL).
- Line charts for trends over time.
- Bar charts for top days by metric.
- Slicer for date range filtering.

## Files
- `hr_attendance_overview.pbix`: Power BI dashboard file.
- `Attendance Sheet 2022-2023_Masked.xlsx`: Dataset (masked).
- `Abbrivations.xlsx`: Abbreviations key.
- `HR_Attendance_Analysis_Report.pdf`: Detailed report.
- `attendance_dashboard.png`: Screenshot of dashboard.

## How to Use
1. Install Power BI Desktop: [powerbi.microsoft.com/desktop](https://powerbi.microsoft.com/desktop/)
2. Open `hr_attendance_overview.pbix` and refresh data.
3. Explore interactive visuals.
